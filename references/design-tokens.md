# 设计规范（design tokens）

所有数值都在 `scripts/primitives.js` 的 `T` / `THEMES` 里，改这一处，四种图型同时生效。

## 画布与栅格

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 13.333 × 7.5 英寸 | 16:9，与 PPT 默认版式一致 |
| 渲染密度 | 288 dpi | 3840 × 2160，投影和打印都够 |
| 左右安全边距 | 0.72 in | 页眉装饰条起点 |
| 内容左边距 | 1.20 in | 图形主体起点（比文字缩进更深，视觉上成块） |
| 内容右边距 | 12.10 in | 图形主体右边界 |
| 页眉分隔线 y | 2.04 in | 标题区与图形区的分界 |
| 页脚基线 | 6.88 in | 注释从这里开始 |

**为什么图形主体比文字多缩进 0.48 in**：文字是流动的，图形是块状的；同一条左边线会让整页显得左倾，图形缩进后视觉重心才稳。

## 字号阶梯

| token | 值 | 用途 |
|---|---|---|
| `T.title` | 27 pt bold | 页面主标题 |
| `T.nodeTitle` | 20 pt bold | 系统节点名（云内主文字） |
| `T.body` | 12 pt | 副标题、卡片标签、步骤名 |
| `T.label` | 11 pt | 链路说明文字 |
| `T.small` | 10.5 pt | 节点副标题、矩阵单元格 |
| `T.tiny` | 9 pt | 页脚注释、序号角标 |

只用这六档，不要出现 13 pt、18 pt 这种中间值——节奏感来自**少而固定的档位**，不是来自精确拟合。

## 主题（8 套）

`meta.theme` 切换，所有颜色、投影、底色一起变，spec 的其余部分不用改。

| theme | 气质 | 主色 | 取色依据 |
|---|---|---|---|
| `corporate-blue`（默认） | 通用商务 | #2B6CB0 | 通用企业蓝，最稳 |
| `consulting-navy` | 战略咨询 | #00338D | 麦肯锡体系：藏青 #051C2C + 蓝 #00338D + 金 #C8A962 |
| `gov-red` | 政务 | #A61B29 | 政务红 + 金 #C9A227 |
| `tech-dark` | 深色科技 | #38BDF8 | 深底 #0F172A + 青色高亮 |
| `minimal-ink` | 极简单色 | #1F2937 | 灰阶极简，弱化一切装饰 |
| `ant-blue` | 产品/互联网 | #1677FF | Ant Design 品牌色 |
| `finance-green` | 金融/医疗稳重 | #0E5C4A | 墨绿 + 金 |
| `warm-sand` | 非技术汇报 | #A0522D | 米色底 + 赭石 |

### 色槽（重要）

`accent` 的五个值 **`blue` / `teal` / `amber` / `violet` / `slate` 是色槽，不是颜色值**：

| 槽位 | 语义 | corporate-blue 下的实际颜色 | gov-red 下的实际颜色 |
|---|---|---|---|
| `blue` | 主色槽（第一个系统 / 去程） | #2B6CB0 蓝 | #A61B29 红 |
| `teal` | 辅色槽（第二个系统 / 回程） | #0F9D8F 青 | #1F6E5A 绿 |
| `amber` | 强调 / 警示 | #C77B22 | #C9A227 金 |
| `violet` | 第三方 / 外部 | #6B5BD2 | #7A4A8C |
| `slate` | 中性 / 附属连接 | #64748B | #6B6259 |

所以 spec 写 `accent: blue` 表达的是「这是主色对象」，换主题后会自动变成该主题的主色。

### 局部改色：palette

不想换整套主题、只想对齐某个品牌色时，用 `meta.palette` 覆盖：

```yaml
meta:
  palette:
    primary: "#C0392B"     # 等价于覆盖 blue 槽
    secondary: "#C9A227"   # 等价于覆盖 teal 槽
    bg: "#FFFFFF"
    ink: "#1A1A1A"
```

可覆盖字段：`primary / secondary / accent / tertiary / neutral`（槽位别名）、`blue / teal / amber / violet / slate`（槽位原名）、`bg / ink / sub / line / surface / gradFrom`。全部必须是十六进制色值，写错会直接报错。

### 颜色推导规则

主题定义里每个槽位只需要一个**品牌色**，浅底色与描边色由混合算法算出，所以新增主题只要给 5 个颜色：

| 项 | 浅底主题 | 深底主题 |
|---|---|---|
| 卡片填充 | 品牌色向背景混合 88% | 背景向品牌色混合 30% |
| 卡片描边 | 品牌色向背景混合 60% | 背景向品牌色混合 55% |
| 投影强度 | 0.07–0.14 | 0.42（黑投影） |

深底必须用相反的混合方向，否则所有卡片都会糊成背景色、失去色相区分。

## 配色

主题 `corporate-blue`：

| token | 值 | 用途 |
|---|---|---|
| `ink` | #14213D | 主文字 |
| `sub` | #64748B | 次要文字 |
| `mute` | #94A3B8 | 注释 |
| `nodeText` | #334155 | 卡片内正文 |
| `line` | #E2E8F0 | 分隔线 |

强调色（每个都有 line / fill / stroke / grad 四件套）：

| accent | 主色 | 语义建议 |
|---|---|---|
| blue | #2B6CB0 | 主体系统、去程数据流 |
| teal | #0F9D8F | 对端系统、回程数据流 |
| amber | #C77B22 | 告警、需要关注 |
| violet | #6B5BD2 | 第三方、外部 |
| slate | #64748B | 中性节点、附属连接 |

约束：一张图里强调色**不超过 3 个**。超过就说明信息层级没理清。

## 线条与形状

| 项 | 值 |
|---|---|
| 主链路线宽 | 0.030 in（≈2.2 pt） |
| 分支链路线宽 | 0.022 in（≈1.6 pt） |
| 箭头 marker | strokeWidth 的 5 倍，圆角连接 |
| 卡片圆角 | 0.12–0.18 in |
| 胶囊圆角 | 高度的一半（全圆） |
| 投影 | `dy 5 / blur 9 / 12%`，卡片用 `dy 3 / blur 5 / 9%` |
| 渐变 | 白 → 强调色 fill，自上而下 100% |

**闭合环的两条弧**端点要纵向错开 0.14 in，否则两条线在端点粘成一坨，看不出是双向。

## 版式通则

- 标题区固定占顶部 2.04 in，图形区从中线到页脚均匀分布
- 页脚注释默认左对齐；只有图形右侧有大片留白时才用 `align: right` 去补重心
- 卡片内文字一律居中、垂直居中；多行时主标题 bold、副标题灰色小一号
